## Project Overview

This project demonstrates data ingestion, exploration, cleaning, and storage of the Netflix dataset using Apache Spark (PySpark) in Databricks.

## Project Workflow

### 1. Data Exploration

This notebook includes:

* Dataset loading
* Schema validation
* Data exploration (rows, columns, schema, unique values)
* Corrupted record detection
* Null value analysis

### 2. Data Cleaning

This notebook includes:

* Handling missing values
* Removing unnecessary records where applicable
* Data validation and quality checks
* Preparing a clean dataset for analysis

### 3. Data Storage

The cleaned dataset is saved in **Parquet** format for efficient storage and faster processing.
